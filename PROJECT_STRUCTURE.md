# FER3ON-AI-V2 Project Structure

## Root layout
- runtime/ — runtime state, logs, and operational artifacts
- archive/ — archived historical documents and reports
- docs/ — current operational documentation
- core/ — core engine and runtime modules
- brain/ — brain and decision support modules
- config/ — configuration modules
- ml/ — machine learning modules
- risk/ — risk management modules
- execution/ — execution utilities
- analytics/ — dashboards and analytics helpers
- testing/ — testing utilities and backtest helpers
- tools/ — developer utilities and helper scripts
- tests/ — regression and compatibility tests

## Runtime folders
- runtime/logs/ — runtime logs and diagnostics
- runtime/state/ — state snapshots and runtime metadata

## Archive folders
- archive/legacy_docs/ — legacy architecture and historical reports
- archive/reports/ — older report files
